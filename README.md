# ETL_MySQL_DW
El proyecto DW_Congresos consistió en diseñar un Data Warehouse de 2 tablas de hechos y 6 dimensiones para integrar 301.517 inscripciones. Mediante pipelines ETL (SSIS) se migró y depuró información de MySQL a SQL Server. Esto generó KPIs de rentabilidad, detectando ingresos por $32.859.650 en conferencias y $29.907.800 en talleres.
